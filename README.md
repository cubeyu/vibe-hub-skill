VibeHub Skill 是一个面向普通人的 Vibe Coding 学习助手。开发过程中看不懂 Agent 回复里的专业说法，可以直接让它结合当前任务用大白话解释。你也可以让 Agent 帮你找到下一步、学懂一个概念，并把它用回真实项目。

Skill 负责学习流程和 VibeHub 知识。写代码、控制浏览器和修改项目仍然来自 Agent 本身的能力。它不会把 Agent 变成通用网页制作、截图还原或代码修复工具。

## 一分钟安装

把下面这段话完整发给你的 Agent：

```text
https://github.com/oil-oil/vibe-hub-skill

帮我安装这个仓库里的 skills/vibehub Skill。
```

第一次使用时，即使你还不知道该学什么，Agent 也会先列出几种容易判断的处境，例如“还没开始做网站”“页面已经有了但重点不清楚”“网站能运行但还没部署”。你只需要选择最像自己的一项。

你也可以直接从一句不专业的话开始：

```text
我想让这个设置改完马上生效，但不知道该用什么控件。带我弄懂。
```

正在开发时也可以随时问：

```text
Agent 说这个表单需要做状态管理。用大白话解释一下，它为什么和当前页面有关？
```

## 它具体能做什么

1. **看懂 Agent 的说法**：从 Agent 回复中找出关键术语，结合当前任务解释它为什么出现、负责什么，以及接下来可以怎样回复。
2. **帮你找到术语**：说出想实现的效果，Agent 帮你找到它的名称并用人话解释。
3. **带你学习主题**：Agent 先让你观察或操作，再用课程解释概念，并安排练习。
4. **结合项目学习**：只讲当前项目真正需要的知识，并帮助你应用和验证。
5. **主动推荐下一步**：不知道学什么时，根据项目或常见目标给出几个具体起点。

本地互动是一种教学方式，不是固定课程。

## 看不懂 Agent 回复时

把不理解的原话贴给 Agent，不需要先找出哪个词是术语。VibeHub 会先处理最影响当前任务的一个概念：

1. 用当前页面、功能或报错说明它在这里是什么意思。
2. 解释 Agent 为什么此时提到它，以及它负责和不负责什么。
3. 给出一句可以直接继续判断或回复 Agent 的话。

简单问题不会被强行扩展成一套课程；视觉或操作确实能帮助理解时，才会打开对应页面。

## 不知道学什么也可以开始

没有明确需求时，Agent 不会只问“你想学什么”，也不会让你先挑陌生课程。它会给出几种容易识别的处境，例如：

- 还没开始，想做出第一个网站
- 已经有页面，但内容挤在一起、重点不清楚
- 正在做表单，不知道保存和错误反馈怎么设计
- 想接入数据，但看不懂 API、前端和后端怎样配合
- 经常反复改代码，想用 Git 回到稳定版本
- 网站已经能运行，想部署并让别人访问

选择一个处境后，Agent 会给出短路线，主动标出建议先学的一步，并立即用一个观察、选择或操作带你开始。你不需要再次挑课程，也不需要学习怎样指挥 Skill。

找到明确术语时，Agent 会直接附上官方页面链接。例如：`这叫文本截断（Text Truncate）`，术语本身可以点击。视觉关系或实际操作更重要时，Agent 会主动在内置浏览器打开经过验证的页面，并告诉你要观察什么。

内置浏览器可用时，Skill 会明确选择它，避免链接被静默切到 Chrome 或系统浏览器。完成本地练习后，你只需回复“完成了”，Agent 会读取练习页的结构化结果，不需要你复制链接或复述选择。

## 可以这样问

| 当你想知道 | 可以直接对 Agent 说 |
| --- | --- |
| Agent 回复里的术语是什么意思 | `Agent 说这里需要做状态管理。用大白话解释它为什么和当前页面有关，并告诉我接下来该问什么。` |
| 一个东西叫什么 | `点一下就展开右侧面板的交互叫什么？` |
| 两个术语有什么区别 | `Switch 和 Checkbox 到底有什么区别？不要只给定义，让我实际比较。` |
| 页面为什么不好看 | `这个页面为什么显得没有主次？结合当前页面带我理解。` |
| 做网站需要学什么 | `我想从零做出第一个网站，需要依次理解哪些术语？` |
| 怎样提升网站质感 | `我想让网站更简约、有呼吸感，应该学习哪些概念？` |
| 怎样把网站上线 | `我想部署自己的网站，先带我弄懂域名、DNS、构建和托管。` |

## 课程和练习是一件事

课程提供准确知识，练习帮助你真正形成判断。一次完整学习通常会这样进行：

1. 从你认识的问题或项目画面开始。
2. 先观察、选择、预测或操作。
3. 用 VibeHub 课程解释名称、原因和边界。
4. 在课程练习或项目专属互动中继续判断。
5. 把结果应用到真实项目并验收。

简单术语可以一句话回答；需要视觉或操作时，Agent 会主动组合课程页与练习。

## 本地互动会因人而异

仓库只提供稳定的互动框架，负责页面外壳、状态、结果记录和本地运行。真正的题目、选项、示例、解释与反馈，由 Agent 根据当前用户和项目生成。

因此，它不是打开一个所有人都相同的演示页，而是可以：

- 用你的设置页讲清楚 Switch 与 Checkbox
- 用你的首页对比视觉层级与留白
- 用你的部署方式解释环境变量和构建产物
- 把几个相关术语组合成一条项目学习路径

互动默认运行在本机。Agent 确定当前学习判断后，会使用相关课程设计题目，并把课程页放进练习的无蒙层浮窗。你不需要先说出主题名称，也不需要主动要求打开页面。第一次使用和普通项目修复不会自动打开页面。

## 学习原则

- **不知道学什么时，主动给方向**
- **先解释当前任务里的意思，再补充正式定义**
- **先体验差异，再补充名称**
- **一次只解决一个理解目标**
- **让用户做判断，不替用户答完**
- **最后回到真实项目验证**

## 数据与隐私

- 知识检索只发送经过程序脱敏的简短问题。
- 常见密钥、网址、邮箱、本地路径和代码块会在发送前移除。
- 本地互动运行在 `127.0.0.1`，生成文件与结果保存在本机。
- Agent 已经看到的项目上下文，仍受所用产品和模型服务商的隐私设置约束。
- 无法访问 VibeHub 时，Skill 会明确说明，不会伪造术语页面和学习路径。

## 开发

需要 Node.js 20 或更高版本。

```bash
npm test
```

需要连接本地 VibeHub 网站时：

```bash
node skills/vibehub/scripts/vibehub.mjs resolve \
  --query "Switch 和 Checkbox 有什么区别" \
  --site-url http://localhost:3100
```
